# Event eligibility

The [official Haunted Hacks page](https://events.ycombinator.com/haunted-hacks-2026)
was read in a browser after a plain documentation fetch returned no page text.

The event is in San Francisco. Participation requires attendance
on site and age 16 or above. The posted schedule sets a hacking window that ends
with submissions. The page names Devpost for submissions and live demos for the
top entries. It favors well-executed products or creative uses of Terse and Agent
Relay, with a preference for using both.

The published rules require code to be created during the event; advance ideation
is permitted. This repository contains code created before the event. Consequently
this build must not be described as an eligible submission without an applicable
organizer exception. The prototype, experiments, source history and recordings keep
their actual creation dates. No submission or organizer contact was made.

Treat the prototype as private research and preparation. Recheck the official page
before any event submission; do not change provenance to imply on-site creation.
